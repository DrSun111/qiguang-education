# 启光教育官网 · GitHub 展示版

本目录是静态展示网站。项目介绍、服务和场景概念图可在 GitHub Pages 浏览。图片是 AI 生成的课程场景概念图，不是活动实拍。

## 发布

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main、目录 / (root)。保存后等待 GitHub Pages 构建，访问仓库 Pages 地址。

## 功能边界

GitHub Pages 仅提供静态文件托管，不能安全实现管理员发布、内部账号登录或受控文件下载。当前展示页没有任何模拟登录、密码或受控下载入口。不要把内部 PPT、未授权学生照片、账号信息或数据库上传到公开仓库。

带 SQLite、管理员发布项目/动态、上传资料及内部账号授权下载的独立 Node 服务端实现已在另一个部署包中；正式上线需要一台受控服务器及域名。中国大陆可访问性需要实测，GitHub Pages 不能保证大陆网络稳定访问。正式大陆站点建议采用大陆服务器与完成备案的域名。
